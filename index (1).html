Генерация юзернеймов

Проверка t.me + Fragment

Как в исходном боте: можно выбрать длину 5–8 символов либо задать первую и последнюю буквы. Проверка выполняется по Telegram и Fragment, имя считается свободным только после обеих проверок.

Выберите длину

Ожидание ответа бота

Чтобы запускать проверку на сервере, подключите API к веб-приложению.

Генератор в исходнике создаёт буквенные варианты (a–z), без цифр и подчёркиваний. Здесь форма сохраняет параметры и передаёт их будущему API.

◇

Скачать видео

Без водяного знака*

Вставьте ссылку на видео. Исходный бот использует yt-dlp и поддерживает YouTube, TikTok, Instagram, X/Twitter и другие платформы.

Запрос подготовлен. После подключения backend бот обработает ссылку и отправит файл в Telegram.

*Возможность скачивания зависит от платформы, доступности ролика и ограничений источника.

Управление каналами

Для администраторов

Чтобы подключить канал, откройте бота и перешлите ему любое сообщение из своего канала — бот должен быть администратором. Уже подключённые каналы показывает кнопка ниже.

ID канала бот присылает в чате после нажатия «Показать мои каналы» — скопируйте его сюда, чтобы использовать инструменты ниже.

Telegram Stars

В исходном боте есть меню пакетов Stars и проверка статуса заказа.

Цены и условия следует получать из текущего обработчика платежей бота, а не задавать статически на сайте.
